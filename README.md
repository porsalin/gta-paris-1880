# Grand Theft Auto: Paris 1880 — La Belle Époque Underground
Fan concept by Adam. Top-down three.js game, 108 missions. Play: https://porsalin.github.io/gta-paris-1880/
Controls: WASD/arrows move/drive, F/Enter enter/exit, Space/Ctrl fire, Q/E weapons, Shift handbrake, Esc/P pause. Gamepad & touch supported.
