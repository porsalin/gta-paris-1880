# Grand Theft Auto: Paris 1890 — La Belle Époque Underground
Fan concept by Adam. Top-down three.js game, 114 missions found in the world (givers, letters, newspapers, rumours). Play: https://porsalin.github.io/gta-paris-1880/ (add `?debug` for the mission menu).
Controls: WASD/arrows move/drive, F/Enter enter/exit, T or click talk, Shift-click pickpocket, Space/Ctrl fire, Q/E weapons, Shift handbrake, Esc/P pause. Gamepad & touch supported.
Story: story_bible.md (regenerate with `python3 gen_bible.py`). Test: `python3 tm2.py [url]`.
